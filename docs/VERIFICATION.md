# 구현 검증 결과

검증일: 2026-10-01 (Asia/Seoul)

## 데이터

- 공식 다운로드 수집 경로를 직접 실행: 전국치매센터표준데이터 321건, 국립중앙의료원 치매안심센터 정보 256건.
- 비교·정규화 후 통합 318개 항목: 안심센터 292, 광역센터 8, 분소·분관 16, 기타 지원기관 2. 출처의 범위이며 전국 전체 기관 수를 뜻하지 않는다.
- 표준자료 최신 기준일 2026-08-14, 국립중앙의료원 기준일 2026-01-28. 개별 센터·프로그램별 출처와 기준일을 상세에 보존.
- MASTER 공개 JSON 62,443개, 약 226 MiB를 같은 상대경로로 동기화. 파일별 SHA-256과 상세 참조 검사 통과.
- 첫 화면 요청은 치매 매니페스트와 압축 인덱스 2개. 전체 장기요양·사진 데이터는 초기 요청 없음. 상세 선택 시 해당 센터 JSON만 요청.

## 자동 검사

- 치매안심 `npm run check`: JavaScript 8개, Python 동기화 4개, 전체 공개 파일 무결성·센터 참조 검사 통과.
- MASTER `tests/test_dementia.py`: 정규화·출처 보존·분소 구분·ID 안정성·행정구역·유형 충돌·좌표 검사 9개 통과.
- MASTER 기존 `npm run check`: 기존 돌봄 데이터·기능 검사 통과. 815개 지역 페이지, 9개 돌봄 유형, 공단 목록/상세/사진 검사 포함.
- `npm run build`: 정적 배포 산출물 생성 성공.

## 실제 Chrome 검사

`tests/browser-check.cjs`에서 데스크톱 1440×1000, 모바일 390×844로 15개 항목 통과:

1. 초기 JSON 두 요청과 자체 Origin
2. 실제 배경 지도 로딩
3. 전국 마커 묶음
4. 광역센터·분소 필터
5. 목록·마커 선택과 상세 지연 로딩
6. 돌봄한눈에 주변 검색 좌표 전달
7. 마커 상세와 Esc 닫기
8. 센터 공유 직접 진입 복원
9. 현재위치 허용 후 검색
10. 검색 결과 없음과 초기화 복구
11. 모바일 가로 넘침·상세·목록 전환 및 결과 보존
12. 데이터 요청 실패 표시와 재시도
13. 현재위치 권한 거부 안내
14. 실제 돌봄한눈 메뉴에서 선택 지역 전달
15. JavaScript 런타임 오류 없음

결과 JSON과 화면 캡처는 `test-results/`에 있다. 이 폴더는 Git에서 제외한다. 타일 지도는 실제 외부 요청을 사용했고, 위치 허용/거부는 브라우저의 테스트 위치와 거부 응답으로 재현했다. 돌봄한눈→치매안심 검사는 아직 게시되지 않은 새 도메인의 도착 응답만 테스트에서 대체하여 전달 URL을 검증했다. 실제 전화·예약·공유 메시지 전송은 하지 않았다.

## 공개 반영 상태

현재 실행 주소는 `http://127.0.0.1:3100/`이다. 위 구현 검증은 최초 푸시 전에 수행했다. GitHub Pages 활성화·DNS 변경은 이 로컬 검증의 범위에 포함하지 않았다. 실제 `dementia.designboard.net`의 공개 동작과 예약된 GitHub Actions 실행은 공개 반영 후 확인해야 한다. 설정 절차는 README에 기록했다.
